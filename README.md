## ✨ Key Features

- 🌌 **Interactive Starfield Particle Mesh**: Custom HTML5 Canvas network reacting in real-time to mouse proximity, clicks, and device viewport resizing.
- ⌨️ **Developer Command Palette / CLI (`Ctrl+K`)**: In-browser terminal emulator supporting commands like `help`, `about`, `projects`, `skills`, `certifications`, `contact`, `theme`, `clear`, and `resume`.
- 🌓 **Dark & Light Mode Engine**: Smooth theme toggle with CSS custom properties and persistent state stored in `localStorage`.
- 🔍 **Interactive Project Showcase**: Filterable project gallery (`All`, `Startups & Web`, `AI & Machine Learning`, `IoT & Hardware`) with detailed modal deep-dives.
- 📄 **Interactive & Printable Web Resume**: Built-in resume viewer modal + standalone printer-optimized resume (`assets/resume.html`) with 1-click print / PDF download.
- 📋 **Contact Hub & Clipboard Actions**: Interactive contact form with input validation and instant 1-click email copy toast notifications.
- 📱 **Responsive & Accessible**: 100% fluid responsive design across mobile (320px+), tablet, and ultrawide screens.
- ⚡ **Zero External Build Dependencies**: Lightning fast, pure vanilla ES6+ JavaScript, CSS3 variables, and semantic HTML5 with zero npm configuration required.
